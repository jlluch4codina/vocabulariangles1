# 🇬🇧 English Vocab & Grammar Trainer

Un'aplicació web interactiva, moderna i adaptativa dissenyada per estudiar i practicar el vocabulari d'oficis (*Jobs*), verbs i frases verbals (*Verbs & Verb Phrases*), així com l'estructura gramatical de **Used to** (rutines del passat).

## 🚀 Característiques principals

La plataforma compta amb **5 modes d'aprenentatge interactius** amb feedback immediat, recompenses de punts d'experiència (XP) i comptador de rínxol (*streak*):

1. **🎴 Flashcards (Targetes de Repàs):**
   * Targetes 3D interactives amb traducció al català/anglès.
   * Filtre per categories (Feines, Verbs o Gramàtica).
   * Pronunciació en àudio mitjançant l'API del navegador (*Text-to-Speech*).

2. **❓ Quiz Mode (Opció Múltiple):**
   * Preguntes de traducció bidireccionals (Català $\rightarrow$ Anglès i Anglès $\rightarrow$ Català).
   * Preguntes gramaticals sobre l'estructura *Used to*.

3. **✍️ Used To (Gramàtica):**
   * Exercicis per completar la forma correcta de *used to* (afirmativa, negativa i interrogativa).

4. **🧩 Matching Game (Joc de Parelles):**
   * Joc de memòria visual i velocitat per emparellar vocabulari en temps rècord.

5. **📖 Word Descriptions:**
   * Llegir descripcions o definicions en anglès i encertar la paraula corresponent.

6. **📝 Sentences (Vocabulari en Context):**
   * Frases d'exemple completes per triar la paraula correcta entre 3 opcions segons el context.

## 🛠️ Tecnologies utilitzades

* **HTML5:** Estructura semàntica i accessible.
* **Tailwind CSS:** Disseny fluid, responsive (mòbil/tauleta/ordinador) i modern.
* **JavaScript (ES6+ Vanilla):** Sense dependències o frameworks externs feixucs.
* **Web Speech API:** Pronunciació nativa en anglès americà.
* **FontAwesome:** Iconografia intuïtiva i atractiva.

## 📥 Instal·lació i ús local

Aquesta aplicació no requereix servidors ni procés de compilació (*build process*).

1. Clona el repositori:
   ```bash
   git clone https://github.com/el-teu-usuari/english-vocab-trainer.git
   ```
2. Entra al directori del projecte:
   ```bash
   cd english-vocab-trainer
   ```
3. Obre el fitxer `index.html` directament a qualsevol navegador web modern.

## 🌐 Publicació a GitHub Pages

Pots publicar aquesta aplicació gratuïtament a la xarxa en 1 minut:

1. Veu a la pestanya **Settings** del teu repositori a GitHub.
2. A la secció **Pages** (menú esquerra), selecciona la branca `main` com a font (*Source*).
3. Fes clic a **Save**. L'aplicació estarà disponible en pocs segons a `https://el-teu-usuari.github.io/english-vocab-trainer/`.
